# Session 2026-05-18 — Track 7: AOI Grid + Pre-Track-7 Audit Fixes

## What was done

### Pre-Track-7 audit fixes (two issues from code review)

**HealSelf / DamageSelf dev-auth gate (High severity)**
Both handlers previously allowed any connected client to modify their own HP in a production deployment. Fixed with a `PD_DEV_CMDS=1` env-var gate:
- `connection.rs`: added `dev_cmds_enabled()` using `OnceLock<bool>` (checked once, cached for process lifetime) and `pub is_dev: bool` field on `PerConnection`, seeded from `from_spawn()`.
- `handlers.rs` `DamageSelf` guard: `if !conn.in_world || conn.hp <= 0.0 || !conn.is_dev`
- `handlers.rs` `HealSelf` guard: `if !conn.in_world || !conn.is_dev`
- Test panel Full Heal still works when server launched with `PD_DEV_CMDS=1`.

**Y-axis drift (Medium severity)**
Server was integrating `Move.direction.y` into position, causing altitude drift (gravity is client-side only):
- `handlers.rs` Move arm: `let v = Vec3f { x: direction.x, y: 0.0, z: direction.z };` (Y zeroed before storing to `latest_direction`)
- `tick.rs`: removed `conn.pos.y += dir.y * speed * dt;`

### Track 7: Area-of-Interest Grid

Replaced "broadcast to all in_world" with a 3×3 cell AOI filter. Entities more than one cell (~120 m) away no longer receive each other's broadcasts.

**New file: `world/aoi.rs`**
- `CELL_SIZE = 120.0` metres
- `cell_for(x, z) -> Cell` using `div_euclid` (correct negative-number behaviour)
- `neighbors(cell) -> [Cell; 9]` — 3×3 neighbourhood
- `AoiGrid` — sparse `HashMap<Cell, HashSet<EntityId>>`; methods: `insert`, `remove`, `update` (returns `gained/lost` cell diffs), `entities_visible_from`, `entities_in_cells`, `can_see`
- 21 unit tests covering all methods

**`world/mod.rs`**: added `mod aoi;`

**`world/connection.rs`**:
- Added `pub aoi_cell: (i32, i32)` (real cell set by tick loop after `from_spawn`)

**`world/tick.rs`** — full AOI wiring across all broadcast phases:
- Player connect: `aoi.insert(char_id, conn.aoi_cell)` after spawn; `newly_in_world` seed loop filters by `aoi.entities_visible_from(conn.aoi_cell)`
- Player disconnect: `aoi.remove(entity_id, leaver_cell)`; `EntityDespawn` filtered to visible peers
- Movement loop: collects `cell_changes: Vec<(ClientId, old_cell, new_cell)>` to avoid borrow conflict; step 5b applies `aoi.update()` and fans mutual `EntitySpawn`/`EntityDespawn` for players, `EnemySpawn` for enemies, `LootBagSpawn` for bags entering the mover's AOI, `EntityDespawn` for all losing visibility
- Position broadcast (step 6): `let visible = aoi.entities_visible_from(sender.aoi_cell); if visible.contains(recipient_id)`
- Enemy position broadcast (step 6b): `let visible = aoi.entities_visible_from(enemy_cell)`
- Enemy spawner: `aoi.insert`; recipients filtered by `entities_visible_from(enemy_cell)`
- Enemy AI loop: collects `enemy_cell_changes`; applies to `aoi` after loop; fan `EnemySpawn`/`EntityDespawn` on boundary crossing
- Enemy corpse cleanup: `aoi.remove`; `EntityDespawn` filtered by visibility
- Loot bag spawn: `aoi.insert(bag_id, bag_cell)`; recipients filtered
- Loot pickup: `aoi.remove(bag_id, bag_cell)` on empty bag; recipients filtered
- Bag expiry: `aoi.remove`; recipients filtered
- New-joiner seed: `can_see(joiner_cell, enemy_cell)` and `can_see(joiner_cell, bag_cell)` gates

**`db/mod.rs`**: added `pub async fn set_character_position()` — test helper that lets integration tests place characters in specific grid cells before connecting.

**`tests/world_two_clients.rs`**:
- `Harness` struct gains `db_url: String`
- `WorldClient` gains `send_heartbeat()`
- Two new integration tests:
  - `aoi_far_apart_clients_dont_see_each_other`: B placed at x=300 (cell 2,0), A at origin (cell 0,0). After both connect, neither receives `EntitySpawn` for the other within 2 s.
  - `aoi_approaching_client_triggers_entity_spawn`: A at origin, B starts at x=300. B walks -X for 12 s (crosses cell boundary at x=240 after ~8 s). A receives `EntitySpawn(B)` and B receives `EntitySpawn(A)` after the crossing. A sends Heartbeat every 4 s to satisfy the server's 10 s app-layer idle timeout during the walk.
