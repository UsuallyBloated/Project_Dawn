## Addendum: read-only world.db viewer + GM access system (server tooling)

The user asked for a way to see accounts and soft-deleted characters, then to get GM access
working ahead of the rest of Phase 1. Both landed in the server repo.

**`admin_report` bin** (read-only) — opens `world.db` with `?mode=ro&immutable=1` and reports
every account + character INCLUDING soft-deletes (`characters.deleted_at IS NOT NULL`), to the
console and to a self-contained, theme-aware `world_report.html` (gitignored). No network surface,
no live-server dependency. First run surfaced 10 accounts / 119 characters (109 soft-deleted) and
that no account had `is_gm` set — which motivated the GM work.

**GM access system — the Phase 1 keystone, built server-only (no client/DLL/wire change):**
- `mint_connect_token` (`world/mod.rs`) packs `is_gm` at `user_data[8]` (bytes 0-8 stay
  `account_id`); `db::account_is_gm` fetches it; the `RequestWorldToken` auth handler passes it in.
- The world connect path (`tick.rs`) reads it via new `parse_is_gm_from_user_data` into a new
  `PerConnection.is_gm`, and logs "GM account connected".
- New `PerConnection::can_use_dev_cmds()` = `is_dev || is_gm`; all six dev-command gates
  (`/give`/`GmCommand`, `HealSelf`, `DamageSelf`, `GrantQuestXp`, both DevSpawn) switched to it.
  So a hosted server runs `PD_DEV_CMDS` off and grants tools to a GM account only; local solo dev
  (`PD_DEV_CMDS=1`) is unchanged. **User decisions:** gate on `is_dev || is_gm` (keep the env-var
  for local dev), audit logging to `gm_actions` deferred to a fast follow.
- **`grant_gm` bin** sets the flag offline: `grant_gm -- <username> on|off`, or no args to list.
  Verified read + write paths on a throwaway copy of `world.db` (real DB untouched).
- 165 lib tests green (added: `user_data` layout roundtrip, `can_use_dev_cmds`). **Not yet ticked:
  wants a playtest** (GM account gets `/give` etc. with `PD_DEV_CMDS` off; a plain account refused).
  Handoff §0 + the To-Do `is_gm` item annotated BUILT so Phase 1 starts at the Respawn dead-check.
