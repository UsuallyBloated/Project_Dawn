# Session 2026-09-10: The Phase 4 Content Survey and Plan

Remote session (user away from the desk). No code changed; the deliverable is
`docs/design/phase4_content_plan.md`, the "evening's worth of content" plan the
schedule's phase 4 calls for, grounded in a full survey of the real content data on
both repos rather than memory.

## What was surveyed (all verified in source)

- Server `zone_camps.toml`: 9 camps / 27 spawns, levels 1, 2, 3, 5, 6, 9, 10, 14, 16.
- Server `quests.toml` + client `quest_definitions.gd` / `dialogue_definitions.gd`:
  4 real quests in two NPC chains (Aldric: wolf, Rotfang; Brom: rat, gnoll) + dev
  `test_q1`; kill-only objectives with bidirectional substring matching.
- `named_mobs.toml`: 5 authored named mobs with full loot, **zero placed**;
  placement is a one-line `named_id` camp tag (the file documents it).
- `npcs.toml` + `world.tscn`: 5 placed NPCs; `vendor_definitions.gd`: 10 authored
  vendor types, 2 placed, neither selling gear.
- `items.toml` (172 items, 42 gear), `loot.rs` (11 tables, no gear drops, 7 tables
  unused by any camp, 4 camps matching no table), `progression.rs` (band + kill XP
  constants).

## Broken content found (section 3 of the plan)

1. **`wolf_threat` is uncompletable**: no mob in the world matches "Wolf". The
   first quest a new player gets cannot be finished.
2. **`rotfang_hunt` is uncompletable**: Rotfang is never spawned.
3. **`gnoll_raiders` (level 3) only matches the level 10 Gnoll Brute.**
4. Elara's dialogue tree (with the Greywood lore hook) is unreachable; she is a
   plain vendor node and is absent from `npcs.toml`, working only via Brom's 15 m
   vendor radius.
5. Rat quest flavor mismatch (cellar vs outdoor camp), harmless.

## The math (section 2)

Even-con kill = `mob_level² × 262.5`; band = `(L³ − (L−1)³) × 1000`; ~11 even-con
kills per level solo at any level, about double the events for a duo (split pool).
With stated pull-cycle assumptions a fresh duo lands at level 6 to 8 in three
hours. Two pacing holes: a **7-to-8 wall** (nothing between the L6 ghouls and the
L9 crypt) and a mild level 4 sag.

## The plan (sections 4 to 7)

First draft patched around the existing camps; the user then called mid-session
that the layout is disposable ("We are not at all connected to this layout"), so
the committed plan proposes a **full replacement `zone_camps.toml`**: 16 camps + 5
named single-spawn dens (54 spawn points, up from 27), a continuous even-con
ladder 1 through 7 then 9/10/12/14/16, every quest target spawning where its
dialogue says, all five named mobs placed, and mob names chosen so a loot table
backs every camp below 14 (two renames: Plagued Ghoul to Plagued Zombie, Undead
Champion to Skeleton Champion). Plus five second-tier quests through the existing
NPCs, a Blacksmith vendor as the coin sink, and Elara upgraded to a dialogue NPC.
The camp table is server-data only, one deploy (plus updating the zones.rs test
that pins 9/27). Procedural dungeon explicitly deferred past Oct 5 (multi-zone
infrastructure does not exist). Five phone-answerable decisions close the doc;
nothing builds until the user answers.
