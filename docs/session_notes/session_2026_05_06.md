## `scripts/net/protocol.gd` (new)

`class_name NetProtocol extends RefCounted` — stateless library; no autoload registration. Static methods only.

### Auth (JSON over WebSocket)

- Message tag constants for both directions: `AUTH_REGISTER` / `AUTH_LOGIN` / `AUTH_CHAR_LIST` / `AUTH_CHAR_CREATE` / `AUTH_CHAR_DELETE` / `AUTH_LOGOUT` / `AUTH_REGISTER_OK` / `AUTH_LOGIN_OK` / `AUTH_CHAR_CREATED` / `AUTH_CHAR_DELETED` / `AUTH_LOGOUT_OK` / `AUTH_ERROR`. (`AUTH_CHAR_LIST` doubles as the server reply tag — same wire string in both directions.)
- `ErrorCode` snake_case strings: `ERR_NAME_TAKEN` / `ERR_AUTH_FAILED` / `ERR_VERSION_MISMATCH` / `ERR_SESSION_EXPIRED` / `ERR_BANNED` / `ERR_INVALID_INPUT` / `ERR_NOT_FOUND` / `ERR_INTERNAL`. Match `serde(rename_all = "snake_case")` on the Rust enum exactly.
- Builders return `Dictionary` shaped to `serde(tag = "type")`: `make_register`, `make_login`, `make_char_list`, `make_char_create`, `make_char_delete`, `make_logout`. `email` is omitted from the register dict when empty (Rust side uses `#[serde(default)]` so missing field deserialises to `None`). `class` is reserved in GDScript so the create-character param is `char_class`; the dict key remains `"class"` to match the wire format.
- Wire helpers: `encode_auth(msg) -> String` wraps `JSON.stringify`; `decode_auth(text) -> Variant` returns `null` on parse failure or non-Dictionary payload.
- `CLIENT_VERSION = "0.1.0"` — matches the server's `MIN_CLIENT_VERSION` default. Bump in lockstep.

### World (bincode over UDP — types only)

bincode ser/deser is deferred to the GDExtension shim that ships with the net adapter (track D). This file mirrors the *shapes* so calling code can be written against named constants today.

- `enum DamageType` — explicit values 0..9 to match the Rust `#[repr(u8)]` ordering.
- `enum ChatChannel` (8) / `EquipSlot` (9) / `KickCode` (5) / `QuestStatus` (3) — name-only; ordinals follow Rust's variant order.
- `SlotRef` tagged-union helpers: `slot_base(idx)` / `slot_bag(base, slot)` / `slot_equip(equip_slot)` produce dicts with a `"kind"` discriminator (`SLOT_BASE` / `SLOT_BAG` / `SLOT_EQUIP`).
- `Vec3` helpers: `vec3(x, y, z)` / `vec3_from_godot(Vector3)` / `vec3_to_godot(Dictionary) -> Vector3`.
- 36 `W_*` constants (Client → Server) and 28 `SW_*` constants (Server → Client) — one per Rust variant, exact match on the wire string.
