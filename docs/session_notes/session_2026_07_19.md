  optimistically client-side regardless of the server; the actual `HealSelf` is refused
  (`handlers.rs:771`, `can_use_dev_cmds`) and the display self-corrects on the next update. A display

  gameplay (`DeathBroadcast` gates only on `!ready`, not GM), never a dev power.
The Test Panel is a client tool that mixes server-gated dev commands with client-side helpers and
legitimate actions; the security-relevant commands (give / xp / level / spawn / server-side heal)
are all correctly gated.
