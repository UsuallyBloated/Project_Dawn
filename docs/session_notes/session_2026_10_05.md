# Session 2026-10-05 — Nine spells that did nothing online now work

The user asked what to work on. The recommendation was Bind and Gate (waiting on the six
decisions in `bind_and_gate.md` §7), with the client-only spell backlog as the piece that
needs no decision. This note covers the backlog; it is appended to if the day goes further.

## 1. The client-only spell backlog, recounted

The To-Do has carried "~32 spells missing from `spells.toml`" since 2026-07-22. A script
comparing the two files gave the exact picture: the client has 156 spells, the server had
124, and the 32 missing split three ways.

| Group | Count | Why it was missing |
|---|---|---|
| Ordinary class nukes | 13 | Never ported |
| Ports | 10 | Gate, Succor, Evacuate plus seven zone ports |
| Blocked on other systems | 9 | Seven prestige-class spells, Camouflage (stealth), Warder's Mend (pet heal) |

Of the 13, nine are plain direct damage with nothing the server's ENEMY arm does not already
do. The other four are not:

- **Dark Decay and Entangle are damage over time**, and the server has no DoT model at all
  (no field in the spell struct, no ticking effect on an enemy). They are also the only two
  DoT spells in the game, and most of their damage is the DoT (168 of 188, and 90 of 100), so
  porting the direct hit alone would ship a spell that does a tenth of what its tooltip says.
- **Exsanguinate** is a mana drain; no server field.
- **Torpor** is authored as an ENEMY spell that heals over time and slows attacks. That reads
  like the Shaman's ally heal with the wrong target type. Left alone; a question for the user.

Checked on the way: the 124 spells both sides already shared show **zero drift** on damage,
mana cost, cast time, cooldown and level. The lockstep has held.

## 2. The port

Server `c0046af`. Nine entries appended to `spells.toml` under their own dated section, values
generated from the client's definitions and unchanged: Blizzard, Thunder Clap (Wizard);
Bloodfire, Void Lance, Tempest Bolt (Sorcerer); Cascade of Stars (Enchanter); Chorus of Misery
(Bard); Feral Shriek (Beast Master); Judgment (Paladin). All nine are Evocation on both sides
(the server falls back to it for any name its table lacks, and the client's table agrees).

The file's header still said buffs, HoTs and CC were "intentionally absent", which stopped
being true months ago. It now says what the server models and what it does not, which is the
list that decides whether a spell can be ported.

No client change. These have always been on the client's bars, so they start working for the
testers' current build the moment the server is redeployed.

No review pass: this is nine data rows through an existing code path, plus two tests.
