## Traps / carried forward
- `PD_DEV_CMDS` enables dev commands ONLY when it equals exactly `"1"`. In PowerShell, bare
  `null` / `false` are not literals (use `$null` / `$false`, a string, or
  `Remove-Item Env:\PD_DEV_CMDS`).
- The red text when running the server via `... *>&1 | Tee-Object` is cargo warnings + the server's
  own stderr logs rendered red by PowerShell, NOT errors. Keep `*>&1` — the server logs to stderr,
  and that's what fills `server.log`.
- Two `*_LINGER_SECS` constants used to share a name; fixed. Player corpse decay =
  `corpses::CORPSE_LINGER_SECS` (7 days); dead-enemy despawn = `mod.rs ENEMY_DESPAWN_LINGER_SECS`
  (5 s). Don't reintroduce the collision.
- `git commit -F <file>` for any commit message containing a `;` (a PowerShell here-string mangles
  it). The Bash tool's working dir drifts — `cd /f/Projects/server &&` before cargo, or use
  `git -C`.
