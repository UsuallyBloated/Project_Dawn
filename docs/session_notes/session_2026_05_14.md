## Sub-task 5 — Server-side group state + group XP via renet (3 commits)

`world/groups.rs` holds `GroupManager` (in-memory): `groups: HashMap<GroupId, Group>`,
`member_to_group` reverse lookup, `pending_invites` for the handshake.
Invite flow: A sends `GroupInvite{name}` → server resolves name → records
pending invite → fans `GroupInvited` to B → B sends
`GroupAcceptInvite{from=A}` → server adds B → fans `GroupRoster` to all.
Leave / kick remove the member; one-member-left groups dissolve.

Kill-credit XP split: server's enemy-death branch finds the killer's
online group, pools `base_xp × 1.20`, divides evenly. Solo killer gets
full base XP (no bonus). Mirrors legacy `GroupManager.distribute_kill_xp`.

Disconnect cleanup: `group_manager.leave(client_id)` runs in the
ClientDisconnected branch; surviving members get a fresh `GroupRoster`.

Client: `Net.broadcast_group_*` wrappers + `world_group_invited` /
`world_group_roster` signals. `GroupManager` autoload listens to both;
launcher-mode action methods route through `Net`. Legacy enet RPC paths
stay for Test Room single-player.

Chat commands: `/invite <name>`, `/accept`, `/leave`, `/kick <name>`.
