# Session 2026-06-15 — Group loot rights + coin drops (the economy faucet)

Picked the next backlog item after the item-weight pass: **coin loot drops**. It grew,
by user design, into a full **group loot-rights system** — because "coin auto-splits to
the group" is meaningless without "this corpse belongs to the killer's group" first.
Built server-authoritative across both repos (client `Project_Dawn` + server
`F:\Projects\server`), wire bumped **PD_W0013 → PD_W0014**.

Design contract: `docs/design/group_loot_and_coin.md` (locked via several user rulings).
Playtest: `docs/playtest_notes/group_loot_coin_checklist.md`.

## The problem it solves
Coins existed end to end (four-tier wallet, vendor buy/sell, encumbrance, item weights)
but **never entered play** — the only faucet was the `GiveCoins` dev command. And loot
had **no ownership**: anyone in range could loot any corpse. This session added the
faucet *and* the rules.

## User-locked design decisions
- Coin **auto-acquires** on loot (no slot, no decline), EQ-style.
- A corpse belongs to the **kill-creditor's group** (or solo killer); strangers locked out.
- Loot **mode** is per-group, leader-set, default **Round Robin**: RR rotates item turns
  per corpse + auto-splits coin to nearby group; **FFA** = anyone loots, coin to the looter.
- Coin split is **proximity-gated at 30 m** from the corpse (the member who walked back to
  town gets nothing); even split, remainder copper to the looter.
- **`/autosplit off`** (per player, EQ-style): coin *you* loot stays with you.
- XP split stays **distance-agnostic** (unchanged) — a deliberate asymmetry vs coin.

## Method note (for future cross-wire work)
Built in small slices, each compiled + tested + DLL-rebuilt before the next. The trip
hazard is signal-signature drift: any change to an existing gdext `#[signal]` must move in
**lockstep** with its `net.gd` handler + a DLL rebuild, or emits mismatch at runtime. The
`/autosplit` slice was sequenced first precisely because it adds a *new* sender and touches
*no* existing signal — proving the PD_W0014 pipeline at minimum blast radius.
