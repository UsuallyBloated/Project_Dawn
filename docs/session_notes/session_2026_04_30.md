## Code — Day/Night Mob Behavior

`scripts/enemy_spawner.gd`
- Added `@export var night_only: bool = false` under new "Spawn Conditions" group
- `_is_night()` helper: true when `hour >= 20 or hour < 6`
- `_ready()` connects `TimeOfDay.hour_changed`
- `_on_hour_changed(hour)`: spawns at hour 20, despawns (queue_free) at hour 6
- `_spawn()` returns early when `night_only and not _is_night()` — handles scene-load during daytime and respawn-timer-fires-during-day edge cases
- Pair with high `shadow_resist` on undead spawners for the full effect

## Code — Stun / Root / Slow / Silence

`scripts/enemy.gd` — new state-effect methods, all guard on `is_dead`:
- `stun(duration)` — sets `_stun_timer`; physics loop skips movement AND attacking; emits `Combat.enemy_stunned`
- `root(duration)` — sets `_root_timer`; blocks movement in `_tick_chase()` but allows attacking
- `snare(amount, duration)` — reduces `move_speed` by `amount` fraction
- `apply_attack_slow(amount, duration)` — scales attack cooldown by `(1.0 + amount)`
- `silence(duration)` — blocks spell casting while `_silence_timer > 0`; emits `Combat.enemy_silenced`
