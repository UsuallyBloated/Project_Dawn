# docs/concepts/world/roster — Directory Index

Enemy and NPC rosters for the world of Project Dawn.
Zone-specific lore for individual enemies belongs in zone files; these documents are the cross-zone lists used for content tracking and spawn design.

---

## Contents

| File | Contents |
|---|---|
| [enemies.md](enemies.md) | Regular enemy roster — sorted by level range; zone, behavior notes, notable drops; excludes named dungeon bosses |
| [named.md](named.md) | Named and boss enemy list — spawn windows, loot notes, level, zone; rare spawns and dungeon bosses |
| [npcs.md](npcs.md) | NPC roster — non-combat characters across all zones; vendor, quest-giver, and flavor NPC listings |

---

*Individual NPC lore profiles with full backstory live in `docs/concepts/world/npc_*.md`. This directory is for roster tracking, not character writing.*
