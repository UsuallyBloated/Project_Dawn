# The Grand Clock Tower — Cogsworth

*The tallest structure in Cogsworth, extending from Level 1 through a purpose-bored shaft all
the way to the plateau surface. The clock face visible on the mountainside is the tower's top.
It has kept perfect time for 312 years. Gnomes will correct you if you say 311.*
