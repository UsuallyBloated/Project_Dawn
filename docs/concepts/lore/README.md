# docs/concepts/lore — Directory Index

Foundational lore documents that don't belong to a single zone, race, or system.
These files establish the world's deep history, its fracture points, and its ritual underpinnings.

---

## Contents

| File | Subject |
|---|---|
| [pre_history.md](pre_history.md) | **The Predecessors** — the civilization that predates the Kel`varath empire; the Minotaur Displacement (the Narrowing); the Bone Citadel; how the Kel`varath built Ixareth-Kul on top of what was already there; connecting threads across five dungeon sites |
| [dark_elf_schism.md](dark_elf_schism.md) | **The Schism** — why there are two kinds of Elves; the four-hundred-year-old argument about magical power and the living world; what both sides did and what both sides remember; why neither account is wrong |
| [revenant_ritual.md](revenant_ritual.md) | **The Revenant Ritual** — the Unmarked Threshold (exists simultaneously in Vel'Sharath, Sunken Ziggurat, and Ixareth-Kul); the Residue; what the pact asks and what it gives; why Evil alignment is evidence rather than requirement |
| [characters.md](characters.md) | **Portrait Concept Art** — oil painting descriptions for 18 race/class combinations; intended as reference for character select art, loading screens, or in-game portrait frames; reads as written art direction, not lore |
