NOTES FOR MODELERS

✓ Tiny Races (Fae, Gnome, Halfling):
  - Large expressive eyes relative to head size
  - Childlike proportions with adult mannerisms
  - Short legs, stockier build
  - ~60–70% of human model scale

✓ Standard Races (Elf, Human, Dark Elf, Felhari):
  - Typical 1/7 head-to-body ratio
  - Proportional limbs
  - Variation: Elves more graceful, Humans balanced, Felhari athletic
  - ~85–100% of baseline scale

✓ Humanoid-ish Larger (Dwarf, Kel`varath, Half-Elf, Half-Ogre):
  - May have unique facial features (reptilian scales, anvil-like face, etc.)
  - Still roughly proportional, but sturdier
  - ~100–125% of baseline scale

✓ Monstrous (Minotaur, Ogre, Troll):
  - Exaggerated features: horns, tusks, distorted face
  - Proportionally shorter heads (1/9 ratio)
  - Longer arms, barrel chests
  - ~130–150% of baseline scale

✓ Creatures (Wolves, Spiders, Bats):
  - Non-humanoid collision models
  - Movement systems account for quadruped/multi-legged locomotion
  - Shoulder height = listed height (for comparison with humanoids)
